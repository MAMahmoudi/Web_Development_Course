PHP

PHP is a server-side scripting language used to build dynamic web pages. It processes forms, stores data in MySQL databases, manages sessions and cookies, and produces the HTML (or JSON) that is sent back to the browser. To run PHP locally we use XAMPP (see Lab 1).
